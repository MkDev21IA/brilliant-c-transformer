# The Brilliant C Transformer
A zero-dependency C playground to learn MLP, Bigram and Transformer

And yes, I already did that in Python, but I think its more challenging in a language like C, and I love challenges, so let's do it. I will learn while I develop this.

## Steps
I think to divide that project in three steps:
1. Build a **Multi-Layer Perceptron (MLP)** for a simple feed-forward network
2. Implement a basic tokenization and a lookup table to predict the next token with a **Bigram Model**
3. Finally, introduce the Multi-Head Self-Attention and LayerNorm components with the **Transformer Block**
